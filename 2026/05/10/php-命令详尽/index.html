一、算术运算符（做数学计算）

符号 名称 示例 结果
+ 加法 $a + $b 两数之和
- 减法 $a - $b 两数之差
* 乘法 $a * $b 两数之积
/ 除法 $a / $b 两数之商
% 取模（余数） 10 % 3 1（余数）
** 幂运算 2 ** 3 8（2的3次方）

二、赋值运算符（给变量存值）

符号 示例 等价于
= $a = 5 把右边值赋给左边
+= $a += 3 $a = $a + 3
-= $a -= 2 $a = $a - 2
*= $a *= 4 $a = $a * 4
/= $a /= 2 $a = $a / 2
%= $a %= 3 $a = $a % 3
.= $str .= “hello” $str = $str . “hello”（拼接字符串）
**= $a **= 2 $a = $a ** 2

三、比较运算符（判断真假，返回 true/false）

符号 名称 示例（$a=5, $b=’5’） 结果
== 等于（值相等） $a == $b true
=== 全等（值和类型都相等） $a === $b false（一个是整数，一个是字符串）
!= 或 <> 不等于 $a != 3 true
!== 不全等 $a !== $b true

大于 $a > 3 true
< 小于 $a < 10 true
= 大于等于 $a >= 5 true
<= 小于等于 $a <= 4 false
<=> 太空船运算符（PHP7+） $a <=> $b 0（相等），1（左边大），-1（右边大）

四、逻辑运算符（组合条件）

符号 名称 示例 说明
&& 与 $a && $b 两个都为真才真
|| 或 $a || $b 至少一个为真即真
! 非 !$a 取反
and 与（优先级低于 &&） $a and $b 同上
or 或（优先级低于 ||） $a or $b 同上
xor 异或 $a xor $b 一真一假才真

五、位运算符（操作二进制位）

符号 名称 示例 说明
& 按位与 5 & 3 1（0101 & 0011 = 0001）
| 按位或 5 | 3 7（0101 0011 = 0111）
^ 按位异或 5 ^ 3 6（0101 ^ 0011 = 0110）
~ 按位取反 ~5 将所有位反转
<< 左移 5 << 1 10（相当于乘以2）

右移 5 >> 1 2（相当于除以2取整）
初学者不常用，了解即可。

六、字符串运算符

符号 名称 示例 效果
. 连接符 “Hello “ . “World” “Hello World”
.= 连接赋值 $str .= “!” 在原字符串末尾追加

七、错误控制符

符号 名称 示例 说明
@ 错误抑制符 @$file = fopen(‘xxx.txt’, ‘r’); 压制该行代码产生的警告/错误（不推荐滥用）

八、执行运算符（执行系统命令）

符号 名称 示例 说明
（反引号） | 执行运算符 | $result = ls -la`; | 执行操作系统的命令，返回输出（安全风险高，慎用） |

九、递增/递减运算符（改变变量值）

符号 名称 示例 效果
++$a 前置加加 $b = ++$a 先自增1，再赋值给 $b
$a++ 后置加加 $b = $a++ 先赋值 $b = $a，再自增1
–$a 前置减减 $b = –$a 先自减1，再赋值
$a– 后置减减 $b = $a– 先赋值，再自减1

十、数组运算符

符号 名称 示例 说明
+ 联合 $arr1 + $arr2 合并数组，重复的键保留左边数组的值
== 相等 $a == $b 键值对相同（顺序无关）则为真
=== 全等 $a === $b 键值对相同且顺序相同、类型相同
!= 或 <> 不等 $a != $b 与 == 相反
!== 不全等 $a !== $b 与 === 相反

十一、类型运算符

符号 名称 示例 说明
instanceof 判断对象是否属于某个类 $obj instanceof MyClass 返回 true/false

十二、其他常用符号

符号 名称 用途 示例
$ 变量标识符 声明或使用变量 $name = “Tom”;
& 引用符 创建变量的引用（别名） $b = &$a;
? : 三元运算符 简化 if-else $age >= 18 ? ‘成年’ : ‘未成年’
?? 空合并运算符（PHP7+） 如果变量存在且不为 null，返回本身，否则返回第二个值 $name = $_GET[‘name’] ?? ‘游客’;
?-> 空安全运算符（PHP8+） 避免 null 调用方法时报错 $user?->getName()
:: 范围解析操作符 访问类的静态属性、常量或方法 MyClass::CONSTANT
-> 对象操作符 调用对象的方法或属性 $obj->method()
\ 反斜线 命名空间分隔符 new \MyNamespace\MyClass()
… 可变数量参数/解包 定义可变参数或展开数组 function sum(…$nums) { } / $arr2 = […$arr1];

十三、括号与引号（语法结构）

符号 名称 用途
() 小括号 改变运算优先级、函数调用、if/while 条件
{} 花括号 代码块（函数体、循环体）、变量变量 ${$var}
[] 方括号 数组定义、数组元素访问
‘ ‘ 单引号 定义字符串，不解析变量
“ “ 双引号 定义字符串，会解析变量和转义符
<<< Heredoc 多行字符串，解析变量
<<<’ Nowdoc 多行字符串，不解析变量（PHP5.3+）
引号示例：
php
$name = “Alice”;
echo ‘Hello $name’; // 输出 Hello $name
echo “Hello $name”; // 输出 Hello Alice

十四、注释符号

符号 名称 示例
// 单行注释 // 这是一行注释
# 单行注释（风格不同） # 也是注释
/* / 多行注释 / 多行注释 */
