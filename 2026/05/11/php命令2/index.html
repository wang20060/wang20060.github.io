一、面向对象编程思想

1. 从面向过程到面向对象

面向过程的核心思想是把一个系统按照执行逻辑拆解成一系列的步骤，然后用函数按照顺序把这些步骤依次执行起来。而面向对象则截然相反，它把整个系统中的所有事物抽象成若干个独立的对象，然后通过对象之间的相互协作来共同完成更复杂的任务。也就是说面向对象编程更贴近现实世界的思维方式，代码结构更清晰，维护和扩展也更方便。

2. 类与对象

在学习面向对象时，先理解“类”和“对象”这两个核心概念：

类是对一类事物共有特征的抽象描述，它定义了该类事物该具备哪些属性和行为，相当于一份设计蓝图。

对象则是根据类这份蓝图具体创建出来的实体，是真正存在于内存中的数据实例。

3. 类的成员

类主要由成员属性和成员方法两大部分构成：属性是描述对象状态的变量，方法用于定义对象的某些行为。在定义类成员时需要合理使用**访问修饰限定符（public、protected、private）来控制成员在类外部的可访问程度：

public修饰的成员在任何地方都可以被访问

protected修饰的成员仅允许在当前类及其子类内部可见

private修饰的成员限制最为严格，只能在本类内部使用。

4. 构造方法与析构方法

构造方法：在实例化对象时自动调用，通常用于完成必要的初始化工作，例如赋初值或建立数据库连接。
析构方法：在对象被销毁时自动调用，一般用于释放资源或完成最后的清理工作。

5. 类常量与静态成员

类常量：在类内部使用const关键字定义的常量，所有对象共享且不可被修改。外部可通过类名::常量名的形式直接访问。

静态成员：使用static关键字修饰的属性和方法。静态成员属于类本身而不是某个具体的对象，因此可以不实例化而直接通过类名来调用。

6. 对象克隆

有时候需要建立某个对象的一个副本而又不希望修改原对象影响到副本本身，此时可以使用对象的克隆来处理这些问题。

二、面向对象三大特性（封装、继承、多态）

1. 封装

封装是面向对象编程中最基本的一个原则——把对象的属性和行为捆绑在一起，并尽可能隐藏内部的实现细节。通过将属性定义为private或protected就无法直接从外部进行赋值或读取，而必须通过类提供的统一公共方法间接操作这些属性。这样一来如果后面内部逻辑变了，只要公共方法不变也不会影响到外部调用方的任何现有代码，大大提高了代码的安全性和可维护性。-

2. 继承

继承机制允许一个子类去继承父类里现有的属性和方法，从而提高代码的复用性。在实际开发中如果多个类之间有很多相同的代码，就可以把这些公共代码提取到一个基类中，然后由子类通过extends关键字继承该基类即可直接拥有这些公共功能。值得注意的是PHP中类的继承是单继承模式，一个子类只能直接继承一个父类，这在一定程度上避免了多继承带来的复杂性问题。

3. 多态

多态是指同一个父类的引用在执行过程中可以根据当前时刻实际指向的对象类型不同而表现出不同的行为。一个父类的引用既可以指向父类自己的对象，也可以指向任意一个子类的对象，当调用某个同名方法时系统会根据当前真正的对象类型来决定执行哪个版本的方法。这种特性带来的灵活性是设计可扩展类体系时必须依赖的基础。-

4. 进阶特性：重写、parent关键字、抽象类与最终类

子类可以对父类方法进行重写（Override）以提供自己的具体实现

parent关键字可以在子类中访问被重写的父类方法

abstract定义的抽象类不能实例化，作为基类供其他类继承

final关键字修饰的类不能被继承，修饰的方法不能被重写

三、代码复用机制

1. Trait

PHP是一款单继承的编程语言，编写代码时常常受限于此。Trait（代码复用机制）就是为此而生的一种代码复用组件。一个Trait类似于一个可被插入类中的代码块，其中定义了一组可以在多个不同的类里重复使用的方法。Trait的优先级规则是：子类中的方法会覆盖父类中的同名方法，而Trait中的方法会覆盖父类中的同名方法但会被子类本地定义的方法覆盖。

2. 接口

接口是一种特殊的interface声明，它也可以实现某种意义上的多继承。接口只提供方法的声明而不提供具体的方法实现，需要靠后续的类来实现接口内部声明的所有方法。接口在大型项目开发中常用于统一约束和规范不同类的行为，降低各模块之间的耦合度。

四、MySQL数据库核心操作

1. 基础SQL语句

SQL可以按照字母缩写口诀记忆为增删改查四大操作：

增（Insert） ：INSERT INTO 表名 （字段名列表） VALUES （值列表）

删（Delete） ：DELETE FROM 表名 WHERE 条件

改（Update） ：UPDATE 表名 SET 字段名=新值 WHERE 条件

查（Select） ：SELECT 字段名 FROM 表名 WHERE 条件

2. 列类型与列属性

了解MySQL中每一种列类型适用的场景是设计好的数据库表结构的基础，其中字符串型、数值型和日期型是最常用的三大基础类型。同时还要掌握列属性的使用（如DEFAULT设置默认值、NOT NULL是否允许为空、UNIQUE保证数据的唯一性等），来完成对字段的更精细约束。

3. 高级查询技术

限制更新与限制删除：某些操作不小心就会导致惨重的后果，加LIMIT可以限制更新或删除的数据行数来防止意外修改太多行

三大查询模式：联合查询（合并多个查询的结果集）、子查询（在一个SELECT语句内部嵌套另一个SELECT）、链接查询（把多个表按关系连接在一起取出需要的数据）

五、MySQL高级特性

1. 数据库备份与还原

在生产环境下定期做数据备份是必须有的环节。备份和还原是防止重要数据因为误操作或硬件故障丢失、永久恢复的核心手段。

2. 用户权限管理

主要包括创建数据库用户、分别授予不同用户不同级别的权限（例如只读权限、可写权限或完全控制权限）、收回某些不必要的权限、最后删除用不着的用户账号，这样才能实现最低权限原则确保数据安全。-11

3. 事件编程的学习主线

包括学习事务（Transaction）的开启、提交和回滚机制，学习存储过程的定义和调用，以及学习触发器的概念与应用场景。

六、PHP操作MySQL

1. 连接与基本操作

使用PHP内置的MySQLi扩展或PDO扩展可以非常方便地连接到MySQL数据库并执行查询操作，之后便可以在PHP代码中完成增删改查、错误处理等操作。

2. 数据安全

在开发Web应用时，要考虑的数据安全问题绝不仅仅是如何把功能跑通。在实际场景中不安全的SQL拼接最容易造成SQL注入漏洞，所以在操作数据库时要养成使用PDO预处理语句的好习惯，把SQL的执行逻辑与用户输入的数据分开处理，确保用户传入的数据无法随意篡改SQL的结构。
