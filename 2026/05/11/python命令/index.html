Python零基础笔记

本笔记为精简版，只保留最核心语法和示例。

第一章：Python基础语法

1.1 注释

# 单行注释

###  1.2 变量
name = "张三"
age = 18
a, b = 10, 20   # 同时赋值
x, y = y, x     # 交换变量

字母、数字、下划线组成，不能数字开头

见名知意，蛇形命名：my_name

# 第二章：数据类型
2.1 常用类型
类型	示例
int	age = 18
float	price = 19.9
str	name = "张三"
bool	True / False
None	None

float("3.14")   # 3.14
str(100)        # "100"

第三章：运算符
算术运算符
运算符	说明	示例
+ - * /	加减乘除

**	幂	2**3=8

== != > < >= <=

and、or、not

第四章：输入与输出
输出 print()

age = int(input("请输入年龄："))

第五章：条件判断

if 条件:
    # 执行
elif 条件:
    # 执行
else:
    # 执行

第六章：循环
while循环

i = 1
while i <= 10:
    print(i)
    i += 1
for循环

for i in range(5):      # 0,1,2,3,4
    print(i)
break / continue
break：跳出整个循环

continue：跳过本次循环

# 第七章

s = "Hello"
s[0]      # 'H'
s[-1]     # 'o'
s[0:3]    # 'Hel'
s[::-1]   # 反转
常用方法
方法	作用
len()	长度
upper()/lower()	大小写转换
strip()	去首尾空格
split(",")	分割成列表
"-".join(list)	连接成字符串
第八章：列表
创建与访问

lst = [1,2,3]
lst[0]   # 1
lst[-1]  # 3
常用操作
操作	代码
追加	append(x)
插入	insert(i,x)
删除	remove(x)
弹出	pop(i)
排序	sort()
长度	len(lst)
第九章：元组
用小括号 ()，不可变

t = (1,2,3)
t[0]   # 1
# t[0]=10  ❌ 报错

第十章：字典
创建与访问

d = {"name":"张三", "age":18}
d["name"]       # 张三
d.get("age")    # 18
常用操作
操作	代码
添加/修改	d[key] = value
删除	del d[key] 或 pop(key)
获取所有键	keys()
获取所有值	values()
获取键值对	items()

第十一章：函数基础
定义与调用

def 函数名(参数):
    """说明文档"""
    return 返回值
示例

def add(a, b):
    return a + b

result = add(3,5)   # 8
None类型
无return的函数默认返回 None

一、面向对象编程思想1. 从面向过程到面向对象面向过程的核心思想是把一个系统按照执行逻辑拆解成一系列的步骤，然后用函数按照顺序把这些步骤依次执行起来。而面向对象则截然相反，它把整个系统中的所有事物抽象成若干个独立的对象，然后通过对象之间的相互协作来共同完成更复杂的任务。也就是说面向对象编程更贴近现实世界的思维方式，代码结构更清晰，维护和扩展也更方便。 2. 类与对象在学习面向对象时，先理解“类”和“对象”这两个核心概念： 类是对一类事物共有特征的抽象描述，它定义了该类事物该具备哪些属性和行为，相当于一份设计蓝图。 对象则是根据类这份蓝图具体创建出来的实体，是真正存在于内存中的数据实例。 3. 类的成员类主要由成员属性和成员方法两大部分构成：属性是描述对象状态的变量，方法用于定义对象的某些行为。在定义类成员时需要合理使用**访问修饰限定符（public、protected、private）来控制成员在类外部的可访问程度： public修饰的成员在任何地方都可以被访问 protected修饰的成员仅允许在当前类及其子类内部可见 private修饰的成员限制最为严格，只能在本类内部使用...
